# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
  
## PROCEDURE

### 1. Open Autodesk Fusion 360:
   Launch Autodesk Fusion 360 on the computer and sign in using the Autodesk account. Create a new design file by selecting File —> New Design.

### 2. Create a New Sketch:
   From the Design workspace, select the Create Sketch option from the toolbar. The sketch environment will open with the available construction planes.

### 3. Select the Sketching Plane:
   Select the appropriate plane (XY, XZ, or YZ) according to the given drawing and project requirements. The selected plane will become the working surface for creating the sketch.

### 4. Create the Basic Geometry:
   Use the sketching tools available in Fusion 360 to draw the required geometry. Tools such as Line, Circle, Arc, Rectangle, Polygon, and Point can be used to construct the given sketch accurately.

![image](https://user-images.githubusercontent.com/113594316/198206497-ca83d495-119b-45cd-b43d-8ca3ea7e9544.png)

### 5. Apply Geometric Constraints:
   Apply suitable sketch constraints such as Horizontal, Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, and Symmetry wherever required. These constraints help maintain the correct shape and relationship between the different elements of the sketch.

### 6. Add Dimensions:
   Use the Sketch Dimension tool to specify the required lengths, distances, angles, diameters, and radii according to the given drawing. Enter the exact dimensional values to obtain an accurate sketch.

### 7. Modify the Sketch:
   Use sketch modification tools to correct or edit the geometry. Features such as Trim, Extend, Offset, Mirror, Move/Copy, Fillet, and Delete can be used to modify the sketch as required.

![image](https://user-images.githubusercontent.com/113594316/198206562-68463016-3f32-4a87-aa5b-7a17dd023b31.png)

### 8. Check the Sketch:
   Verify the geometry, constraints, and dimensions carefully. Make sure that the sketch matches the given design and that there are no unwanted or incorrect entities.

### 9. Inspect the Dimensions:
   Use the Inspect feature to measure and verify important dimensions of the sketch. Check the distances, angles, radii, and diameters to ensure that they correspond to the required values.

![image](https://user-images.githubusercontent.com/113594316/198206621-6348e8a3-4bbd-4a1f-96d3-db16fbf933d9.png)

### 10. Finish the Sketch:
  After completing the sketch and verifying all dimensions, select Finish Sketch. This exits the sketching environment and saves the completed sketch within the design.

![image](https://user-images.githubusercontent.com/113594316/198206639-31c4bdb5-b13e-4106-bcf5-125c294aa03e.png)

### 11. Create the Drawing:
  Switch to the Drawing workspace from the completed design. Select the appropriate option to create a drawing from the sketch/model

![image](https://user-images.githubusercontent.com/113594316/198206697-2e3ead2b-7d1e-436e-bc36-aa2e73c1e78e.png)

### 12. Insert and Arrange the Views:
   Place the required views of the sketch/design on the drawing sheet. Adjust the position and scale of the views so that they are clearly visible and properly arranged.

### 13. Add Dimensions and Annotations:
   Add the necessary dimensions, center marks, construction information, and other annotations required for the technical drawing. Ensure that the dimensions are clear and readable.

### 14. Complete and Verify the Drawing:
   Check the final drawing for correct geometry, dimensions, view arrangement, and ISO standard representation. Make any necessary corrections before finalizing the drawing.

### 15. Save the Final Project:
   Save the completed Fusion 360 design and drawing file with the appropriate project name.
